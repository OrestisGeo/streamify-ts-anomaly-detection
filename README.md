# Streamify Time-Series Anomaly Detection Methods

Project #2 for the course **Mining of Massive Datasets**.

The goal of this project is to study anomaly detection methods for time series in both **offline** and **streaming** settings. We use the TSB-UAD benchmark dataset and generate new streaming-like datasets by concatenating time series from different domains.

## Project Overview

Time-series anomaly detection is important in many real-world applications, such as industrial monitoring, healthcare, sensors, and web systems. In this project, we compare traditional offline anomaly detection methods with streaming approaches, where data arrive progressively in batches.

The main idea is to evaluate how different methods behave when the definition of "normal" changes over time due to distribution shifts.
